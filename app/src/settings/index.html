The keyboard forgets its per-key colors when it loses power, and single keys can come back dark after sleep (especially behind a monitor or KVM hub). Both options put the colors back without a click.

Startup color

Stored on the keyboard
Color
The keyboard shows this one color at power-on, before macOS and this app run. Per-key colors can’t be stored on the keyboard. Storing writes the keyboard’s flash memory, so it only happens when you press the button; the current profile is restored right after.

Backup folder

Folder The folder is not reachable right now. For a network share: connect it in Finder.
It may also be a network drive, an SMB share or a folder in iCloud Drive. The backup consists of plain files, not an archive — in an emergency you can get at your profiles without this app.

Back up

Back up automatically after changes
Last backup
Keep deleted profiles

The backup holds all profiles from the profiles folder and the settings of this window.

If you delete a profile here, it does not vanish from the backup at once: it moves to the subfolder “deleted” and stays there for the chosen time. An accidental delete is often noticed days later — until then the copy is still there. If the profile shows up again, it is taken out of there by itself.

Restore

Also works on a freshly set up Mac: choose the folder, and the profiles come back into the app. Existing profiles are not overwritten without asking. Backups from version 1.3 and earlier (plain profile copies) can be restored too.
